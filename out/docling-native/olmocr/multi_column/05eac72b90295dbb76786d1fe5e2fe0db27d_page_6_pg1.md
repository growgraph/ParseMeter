2.6.1. fMRI data analysis

411

Analyses were carried out using the standard image

412

analysis package Statistical Parametric Mapping version 5

413

(SPM5-Wellcome Trust Center for Neuroimaging, London,

414

UK) supplemented by custom software written in the matrix

415

based programming environments IDL (ITT, Boulder, CO) and

416

MATLAB (MathWorks, Natick, MA). Preprocessing of the images

417

was initiated via placement of both the anatomical and func-

418

tional images in AC-PC alignment and in gross registration to

419

one another. Time series realignment using a 6 parameter rigid

420

body algorithm (Cox and Jesmanowicz, 1999; Woods et al., 1993)

421

to reduce the influence of any subject motion was then carried

422

out. Concurrently, field inhomogeneity data were used to correct

423

any geometric distortions in the EPI images using an automated

424

algorithm that takes into account the interaction between motion

425

and inhomogeneities and has been shown to result in an improved

426

coregistration between EPI and T1 images (Cox and Jesmanowicz,

427

1999; Hutton et al., 2002). Anatomical data were then segmented

428

into gray matter, white matter, and bias corrected images. Func-

429

tional data were then spatially normalized to the bias corrected

430

(intensity normalized) anatomical images and spatially smoothed

431

using a kernel with a full width at half max equal to two times

432

the native resolution of the image (i.e. 3mm). Linear drift was

433

accounted for by global normalization across the time series and

434

high-pass filtering. Whole brain analysis was carried out on a pixel

435

by pixel basis using a parametric general linear statistical model.

436

This analysis was confined to gray matter pixels using a custom

437

generated mask to exclude any white matter or ventricle pixels

438

that was applied to the data prior to statistical analysis. Motion

439

parameters were used as covariates within this model to remove

440

the influence of subject motion on the subsequent results. The

441

general linear model fit was based on a flexible boxcar design using

442

the canonical hemodynamic response function and corrections

443

for multiple comparisons were carried out such the probability

444

of a type I error was maintained at 5% (Genovese et al., 2002).

445

Finally, the timecourse of the MR signal was determined in the

446

voxel that showed the local maximum correlation to presentation

447

of the visual stimulus (in visual cortex) or administration of

448

cocaine (in the anterior cingulate). The signal measured under

449

each condition was averaged across all three subjects. Graphical

450

data presentations were created using GraphPad Prism 4 (La Jolla,

451

CA).

j1 ∈ {2, . . . , ℓ+2} with µ1 ∈ ( ̂ QB(Z)Ij1 )Ij1-1 . Similar, to µ2 := (λ1, λ2) ∈ ̂ QB(Z), there exists j2 ∈ {2, . . . , ℓ + 2} with µ2 ∈ ( ̂ QB(Z)Ij2 )Ij2-1 .

Suppose j2 &lt; j1. Since ̂ QB(Z)Ij2 is open, by (2.5) there exist open sets Vk ⊆ RHk with λk ∈ Vk, k = 1, 2, such that V1×V2 ⊎V1 ⊎V2 ⊆ ̂ QB(Z)Ij2 ⊆ ̂ QB(Z)Ij1-1 which contradicts our choice of j1.

Now suppose j1 = j2, i.e. µ1, µ2 ∈ ( ̂ QB(Z)Ij1 )Ij1-1 . By Lemma 3.4 the space ( ̂ QB(Z)Ij1 )Ij1-1 is Hausdorff in its relative topology, which is impossible because we have µ1 ∈ W2 ∩W1 for any choice of open sets Wk ⊆ QB(Z) with µk ∈ Wk. Consequently, we have j1 &lt; j2, and iterating this procedure leads to a sequence 2 ≤ j1 &lt; · · · &lt; jk0 ≤ ℓ + 2 which gives ℓ ≥ k0 - 1, and completes the proof in the case k0 = n. On the other hand, if k0 &lt; n note that by Lemma 3.4 we have

$$\psi ( \bigoplus _ { k = 1 } ^ { k _ { 0 } } ( \widehat { Q _ { B } ( Z ) } ^ { \mathcal { I } _ { j _ { k } } } ) _ { \mathcal { I } _ { j _ { k } } \ 1 } ) = \bigoplus _ { k = 1 } ^ { k _ { 0 } } T _ { j _ { k } - 1 } \subseteq \bigoplus _ { j = 1 } ^ { \ell + 1 } T _ { j }$$

where each Tjk corresponds to a µk, i.e. to an infinite-dimensional irreducible representation. Since ̂ QB(Z) also has one-dimensional irreducible representations by Theorem 2.1 and (2.4), we have k0 +1 ≤ ℓ +1, i.e. the length of QB(Z) is at least k0.

Of course, a combination of Lemma 3.1, Lemma 3.2, and Lemma 3.5 completes the proof of Theorem 1.1.

It remains to prove Proposition 1.2. Recall that the composition series (1.1) is called stratified if for any irreducible representation π of B with π(Jk) ̸= {0} we have π(Jk+1) ̸= π(Jk) [13, Definition 0.3]. Moreover, a solving, stratified composition series coincides with the maximal radical series by [13, Proposition 0.4]. If we abbreviate ℓ := lengthQB(Z), then the series

$$Q _ { \mathcal { B } } ( Z ) \supseteq \mathcal { J } _ { \ell + 1 } \supseteq \mathcal { J } _ { \ell } \supseteq \cdots \supseteq \mathcal { J } _ { 1 } = \{ 0 \}$$

with Jk given by (2.3) is solving of minimal length by Theorem 1.1 and the proof of Lemma 3.2. Using the description (2.4) of the irreducible representations of QB(Z) and the compatibility conditions (2.1) and (2.2), it is straightforward to check that the series (3.1) is stratified. Thus, it is the maximal radical series for QB(Z), hence, an application of Lemma 3.1 completes the proof of Proposition 1.2.

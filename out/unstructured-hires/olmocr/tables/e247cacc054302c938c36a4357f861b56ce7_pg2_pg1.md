# 2 GPS and WFQ

Notice that GPS is an idealized server that does not transmit packets as entities. It assumes that the server can serve all backlogged sessions simultaneously and that the traffic is infinitely divisible. In a more realistic packet system, only one session can receive service at a time and an entire packet must be served before another packet can be served. There are differ- ent ways of emulating GPS service in a packet system. The most popular one is the Weighted Fair Queueing discipline (WFQ) [4], also known as Packet General- ized Processor Sharing or PGPS [13].

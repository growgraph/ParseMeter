## 2.2.4 A Maximum of Storage Capacity for $\mathbf { C O } _ { 2 }$ with $\mathbf { S O } _ { 2 }$

For impurities which have higher critical temperature than that of $\mathrm { C O } _ { 2 } ,$ no storage capacity minimum would occur in the corresponding $\mathrm { C O } _ { 2 }$ mixture. Rather, a maximum can appear based on an analysis similar to that for the non-condensable impurities. This has been verified with calculated results for the $\mathrm { C O } _ { 2 }$ mixture with 2.9 vol % $\mathrm { S O } _ { 2 }$ (the Cansolv absorption system case presented in the previous IEA GHG report PH4/32). As shown in Figure 2.6, a maximum is seen at about 11 MPa, where the storage capacity is increased by over 5%. It should be noted again that the storage capacity is based on pure $\mathrm { C O } _ { 2 }$ (see discussion for Equation 2.5). It is, therefore, interesting to see that in this peak region, the $\mathrm{CO}_{2} - \mathrm{based}$ capacity is above that of pure $\mathrm { C O } _ { 2 }$ . In other words, $\mathrm { S O } _ { 2 }$ does not take any but creates space for $\mathrm { C O } _ { 2 }$ . This can be rationalized from the consideration that $\mathrm { S O } _ { 2 }$ decreases average distance between the molecules of the mixture – an opposite effect of that of the non-condensable gases. This can be taken as one positive effect of the presence of $\mathrm { S O } _ { 2 }$ on $\mathrm { C O } _ { 2 }$ storage. However, $\mathrm { S O } _ { 2 }$ causes more concern with regard to its chemical effects on formation rocks. This will be discussed later.

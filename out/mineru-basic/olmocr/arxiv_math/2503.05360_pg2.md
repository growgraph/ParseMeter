\chi _ { 1 } ^ { \flat } \wedge \chi _ { 2 } ^ { \flat } \to \chi ^ { \flat } , \quad \chi ^ { \flat } \to \chi _ { 1 } ^ { \flat } , \quad \chi ^ { \flat } \to \chi _ { 2 } ^ { \flat } .
$$

$$
( \chi _ { 1 } \wedge \chi _ { 2 } ) ^ { \flat } \leftrightarrow \chi _ { 1 } ^ { \flat } \wedge \chi _ { 2 } ^ { \flat } .

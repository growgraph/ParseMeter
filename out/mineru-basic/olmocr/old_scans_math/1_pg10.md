# INTEGRAL CALCULUS.

## CHAPTER I.

ELEMENTARY INTEGRALS TO BE COMMITTED TO MEMORY.

(1.) $\int \frac { d x } { x } = \log x .$

(2.) $\sqrt{\frac{d x}{a + b x^{2}}} = \frac{1}{\sqrt{a b}} \tan^{-1}\left(x \sqrt{\frac{b}{a}}\right), \quad \int \frac{d x}{a^{2} + x^{2}}$ $\begin{aligned}= \frac{1}{a} \tan^{-1} \frac{x}{a}.\end{aligned}$

(3.) $\int \frac{dx}{\sqrt{a^{2} - x^{2}}} = \sin^{- 1}\frac{x}{a}$

(4.) $\int \frac{-dx}{\sqrt{a^{2}-x^{2}}}=\cos^{-1}\frac{x}{a}$

(5.) $\int \frac{dx}{\sqrt{x^{2} \pm a^{2}}} = \log \frac{(x + \sqrt{x^{2} \pm a^{2}})}{a}.$

(6.) $\int \frac{dx}{\sqrt{2ax - x^{2}}} = \arcsin^{- 1}\frac{x}{a}$

(7.) $\int \frac{dx}{\sqrt{x^{2} \pm 2ax}} = \log \left( x \pm a + \sqrt{x^{2} \pm 2ax} \right)$

(8.) $\int \frac{dx}{x\sqrt{x^{2}-a^{2}}}=\frac{1}{a}\sec^{-1}\frac{x}{a}$
